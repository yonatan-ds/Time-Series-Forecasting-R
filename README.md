## 🚀 Advanced Features (Updated)
This project now includes an **End-to-End Health Data Analysis Pipeline** featuring:
- **Interactive Dashboard:** Built with `Shiny` and `shinydashboard` for real-time data exploration.
- **Dynamic Visualizations:** Uses `Plotly` for interactive trend analysis by cancer type and sex.
- **Advanced Detrending:** Implemented **LOESS (Locally Estimated Scatterplot Smoothing)** for flexible, non-parametric trend extraction.
- **Decomposition:** Detailed 7-year moving average analysis to separate trend, cycle, and remainder components.

## 🛠 Advanced Tech Stack
- **Frameworks:** Shiny, ShinyDashboard.
- **Visuals:** Ggplot2, Plotly, Timetk.
- **Analysis:** Tseries, Urca, Forecast, Tidyverse.
